# 🔬 React Lifecycle Visualizer

A complete visual playground to understand how React components behave during their lifecycle phases: Mounting, Updating, and Unmounting — using both Functional and Class Components.

✨ Includes live logs, fake API simulation, loading states, and cleanup handling!

---

## 🧪 Live Demo

🌐 [View Live on Vercel](https://your-vercel-link.vercel.app)

---

## 🚀 Features

- 🔁 Toggle between Class & Functional component
- 🧠 See real-time visual logs of lifecycle methods
- ⏳ Simulate API call with loading & cleanup
- 🎨 Responsive UI with Tailwind CSS
- 🧩 Compare useEffect vs Class lifecycle methods
